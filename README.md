# Flipkart Analytics Project

Flipkart Analytics Project is an end-to-end data analytics and machine learning project developed as part of the **AICTE | IBM SkillsBuild Data Analytics with AI Internship Program 2026**.

The project analyzes Flipkart product data from multiple categories to understand prices, discounts, ratings, brands, and category-wise trends. It includes data cleaning, exploratory data analysis, feature engineering, machine learning for price prediction, and an interactive Streamlit dashboard.

## Key Features

- Data cleaning and preprocessing
- Exploratory data analysis and visualization
- Category and brand analysis
- Price and discount analysis
- Feature engineering
- Machine learning-based price prediction
- Model evaluation using MAE, MSE, RMSE, and R²
- Interactive Streamlit dashboard
- Organized project structure with reusable Python scripts

## Tech Stack

- NumPy
- Matplotlib
